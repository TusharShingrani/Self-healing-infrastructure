# Scope

This repository concerns Linux infrastructure resource saturation on Kubernetes,
not banking business logic, nginx application repair or arbitrary AI commands.

Read README.md, docs/architecture.md and docs/security.md before changing effects.
Keep telemetry freshness, identity, approval, expected-value checks, signed bounded
intents, durable journalling, independent verification and rollback fail-closed.

Run `python -m unittest discover -s tests -v`. Do not call mocked tests live
evidence. A changed kernel value alone does not establish recovered useful work.
Keep private keys, kubeconfigs, tokens, detailed histories and backups out of Git.

The healer bastion, K3s server and monitor are not destructive experiment targets.
Load only the owned bounded fixtures. Automatic I/O priority repair is unsupported
until its effectiveness and safe target have been separately qualified.
