# Preliminary job pilots retained separately

`jobs-workers-learning.json` recorded three capacity restorations using the
initial verifier. It is preliminary mechanism evidence. Cached pre-repair
client health could qualify, so it is excluded from the final stronger
independent post-action verification claim.

`jobs-workers-learning-verified.json` recorded two fresh independently verified
occurrences, then its third occurrence was blocked. The scripted operator
selected a historical procedure by cause name instead of exact scope when
promoting. The adapter correctly refused automatic use in the new scope. This
is a real misuse case: choosing a familiar procedure name is insufficient.

The runner now selects the unique procedure whose scope, cause, symptoms and
actions all match the verified case. The failed pilot is retained, including
its log, rather than overwritten. Source changes require a new verification
scope. Final learning experiments use separate output files and the final
adapter/client/verifier version.
