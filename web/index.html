Operator audit

Application contract

The supported application is the jobs-lab Kubernetes namespace. API and worker containers process synthetic jobs; PostgreSQL stores the results; a separate VM verifies completion and correctness.

Kubernetes owns

Pod restart, rescheduling and reconciliation to the declared state.

The healer owns

Evidence, investigation, approval, reviewed configuration repair, independent verification and repair memory.

Reviewed configuration changes

Use an incident's reviewed recipe to restore the approved database endpoint, worker count, workload resource settings or network policy. This interface does not allow free-form configuration, shell commands or arbitrary targets. Changing the application contract requires a reviewed reference change and revalidation of learned procedures.

Console preferences

This changes display refresh only. It does not change the healer sampling interval or experimental results.

Scope

This is a single-operator research prototype. Another application needs an adapter, a service contract, bounded repairs and verification tests. Universal plug-and-play and enterprise readiness have not been demonstrated.
