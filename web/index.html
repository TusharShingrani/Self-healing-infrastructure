REVIEWED REPAIR MEMORY
What has the healer earned permission to repeat?
Two distinct, independently verified occurrences plus explicit promotion permit automatic reuse in the same application, resource and procedure scope. A changed application or failed verification requires revalidation. This is procedural learning, not training an AI model.
Operator decision trail
Banking practices represented in this lab
Verified TLS for the statement API and database; separate API and worker database privileges; immutable ledger and completed statements; idempotent requests; recorded decisions; fresh reconciliation after repair; and tested recovery. DORA informs the controls, but this PoC does not establish DORA compliance.
The lab has one operator, one database and one Kubernetes control node. Independent four-eyes approval, production identity, automatic certificate renewal and multi-site recovery are not implemented.
